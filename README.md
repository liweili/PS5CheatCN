# PS5 金手指自动汉化工具

> PS4 / PS5 金手指（Cheat）本地汉化工具 —— 支持 **MC4 / SHN / JSON** 三种格式的打开、编辑、自动汉化、保存与格式转换。

为破解主机的玩家做的离线汉化工具。**不上传任何数据，全部在本机处理。**

| 功能 | 说明 |
|------|------|

| **逐条编辑** | 每个修改项独立列出，单独汉化、单独恢复原文 |

## 🎯 使用流程

1. **打开** 金手指文件（`.mc4` / `.shn` / `.json`），也可以直接拖进窗口
2. 点 **「自动汉化全部」**，左侧列表立刻显示中文名
   （顺手会清掉原文里的乱码问号串、异常符号）
3. 对翻译不满意的，**直接在右侧改**，回车应用
4. 点 **「保存」** —— 弹出保存对话框：
   - 默认**沿用原文件格式**，文件名自动加 `_CN` 后缀（如 `CUSA18740_01.08_CN.mc4`），可改
   - 想换成别的格式？点工具栏的 **「转换格式」** 按钮
   - 署名方式可选：独立条目 / 附加到每个名字后 / 不写
5. 想知道原文长什么样？点 **「查看全文」**，MC4 会自动解密成 XML 显示

> 打开原文件后按 F5 或点「保存」，默认不会覆盖原文件，而是生成 `_CN` 后缀的新文件。

## 🧩 三种格式的技术说明

### MC4（加密格式）

```
Base64( AES-256-CBC( XML ) )
```

- Key：`304c6528f659c766110239a51cl5dd9c`
- IV：`u@}kzW2u[u(8DWar`

密钥与官方 [mc4-cheat-decrypter](https://github.com/bucanero/save-decrypters/tree/master/mc4-cheat-decrypter) 一致。
**解密 → 重新加密与原文件字节级完全相同**，因此保存后不会破坏原始加密格式，主机端可正常读取。

### SHN

明文 XML：

```xml
<Trainer Game="..." Moder="..." Cusa="CUSA00004" Version="01.07" Process="eboot.bin">
  <Cheat Text="Godmode">
    <Cheatline>
      <Offset>215C17</Offset>
      <Section>0</Section>
      <ValueOn>90-90-90-90-90-90-90-90-90</ValueOn>
      <ValueOff>C4-C1-7A-11-96-50-EE-01-00</ValueOff>
    </Cheatline>
  </Cheat>
</Trainer>
```

字节值用连字符格式。

### JSON

明文 JSON：

```json
{
  "name": "inFamous: Second Son",
  "id": "CUSA00004",
  "version": "01.07",
  "process": "eboot.bin",
  "mods": [
    { "name": "Godmode", "type": "checkbox",
      "memory": [{ "offset": "215C17", "on": "909090909090909090", "off": "C4C17A119650EE0100" }] }
  ],
  "credits": ["Weysincha"]
}
```

字节值不带连字符。

## 🔤 汉化引擎

五级优先级，逐级降级：

0. **游戏术语表** —— `Combo` → `连招`（优先级最高，不被通用词库覆盖）
1. **整句精确匹配** —— `Godmode` → `无敌`
2. **前缀规则** —— `Inf HP` → `无限生命值`、`Max Money` → `满金钱`
3. **多词短语替换** —— `Infinite Ammo` → `无限弹药`
4. **单词级替换** —— 兜底，保留数字与按键符号

此外还支持**复数归一化**（`Combos` → `连招`）与**拼音反推**（`(xin zi)` → 资金）。

词库主体来自对 **HEN-Cheats-Collection 全量 12330 条去重条目**的词频统计（数据驱动，而非凭空编写）。

**实测命中率 81.0%**（9985 / 12330）。未识别的主要是游戏专有名词（如 `Griffa`、`Blue Life Crystal`），
这类**刻意不硬译** —— 翻错专有名词比保留原文更糟，可在界面里手动补。

还内置了拼音反推：原作者括号里的 `(xin zi)`、`(jiao dian)` 等拼音注释（中文因编码损坏留下的痕迹）会被还原成「资金」「焦点」等。

## ✍️ 署名自定义

署名是模板制的，默认规则保持不变：

```
————翻译：{作者}，编辑时间{日期}————
```

**可用变量**

| 变量 | 含义 | 示例 |
|------|------|------|
| `{作者}` | 设置里填的译者名 | `L.wl` |
| `{日期}` | 保存当天日期 | `20261104` |
| `{游戏}` | 当前文件里的游戏名 | `eFootball PES 2021` |
| `{版本}` | 当前文件里的版本号 | `1.08` |

在「设置」里可以随意改模板，也有 5 个一键预设：

- 默认规则：`————翻译：{作者}，编辑时间{日期}————`
- 简洁版：`————汉化：{作者} {日期}————`
- 带游戏名：`————{游戏} 中文版，翻译：{作者}，编辑时间{日期}————`
- 方括号版：`[CN] {作者} {日期}`
- 清空 → 回到默认规则

留空或填纯自定义文本都会原样保留，不会被强行套用默认格式。
署名方式可选：**独立条目** / **附加到每个条目名后** / **不写入**。

**三个地方都能改署名**：

| 位置 | 用途 |
|------|------|
| 「设置」→ 署名模板 | 改默认规则，所有保存都用它 |
| 「保存」对话框 → 署名内容 | 保存单个文件时临时改 |
| 「批量处理」对话框 → 署名内容 | 批量处理时临时改（留空则用默认规则）|

三处都有实时预览，改一个字就能看到最终写入的是什么。

## 📦 批量处理

工具栏的「📦 批量处理」可以选一个文件夹，把里面所有金手指文件统一汉化。

**扫描规则**
- 识别 MC4 / SHN / JSON，自动跳过解析不出条目的文件（比如 `package.json`）
- 默认只扫当前层，可勾选「包含子文件夹」
- 自动跳过本工具自己生成的 `_CN` 副本和 `.bak` 备份，不会重复处理

**三种更新方式**

| 方式 | 行为 |
|------|------|
| **生成 _CN 副本**（默认） | 原文件名加 `_CN` 后缀存到原目录，**原文件完全不动**，最安全 |
| **覆盖原文件** | 直接覆盖，覆盖前自动在同目录留一个 `.bak` 备份 |
| **输出到指定文件夹** | 全部输出到另一个文件夹，文件名保持不变 |

还可以统一指定输出格式，实现**跨格式批量转换**（比如整个文件夹的 MC4/SHN 全转成 JSON）。
输出目录不存在会自动创建，目标重名会自动加序号，不会静默覆盖。
